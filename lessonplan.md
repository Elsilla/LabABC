Comienza esta actividad...
¡Teniedo una reunión scrum!

Tu equipo debe crear un tablero de proyecto y luego crear tarjetas e issues para cada tarea. Esto es repetitivo y está destinado a ser utilizado como práctica. Comienza tu primer sprint priorizando las primeras tareas fáciles (las letras como ejemplo) que las personas pueden abordar; una vez que todos terminen sus tareas, cierra la tarjeta y los issues y luego pasa al siguiente issue.

Practica el branching en tu repositorio creando una nueva rama para cada tarea en la que trabajes. Por ejemplo, si te asignan personalmente las letras C - F, entonces crea una rama llamada "letterC-F". Una vez que termines esas letras y hayas terminado con la rama, asegúrate de crear una nueva rama para tus siguientes letras. Por ejemplo, si tu siguiente tarea son las letras G-I, tu rama sería "letterG-I".


Comandos útiles para crear y mover entre ramas...
- `git branch` (muestra las ramas locales actuales)
- `git branch nombreRama` (crea una nueva rama)
- `git checkout nombreRama` (te mueve a la rama especificada)
- `git checkout -b nombreRama` (crea una nueva rama y te mueve a ella)

Cómo subir una rama...
- `git status`
- `git add .`
- `git commit -m 'mensaje'`
- `git status`
- `git pull origin main`
- `git push origin nombreRama`
